Документ фиксирует WebGL hook-context value-flow, executor contract, return mapping и logging map для связки [context.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/core/context.js) / [webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js).


## 1. Нормативная база WebGL return

По WebGL IDL/API:

| API | Нормативный return |
|---|---|
| `getParameter(pname)` | `any` |
| `getSupportedExtensions()` | `sequence<DOMString>?` |
| `getExtension(name)` | `object?` |
| `readPixels(...)` | `undefined`, данные пишутся в `pixels` |
| `getShaderPrecisionFormat(...)` | `WebGLShaderPrecisionFormat?` |
| `shaderSource(shader, source)` | `undefined` |
| `getUniform(program, location)` | `any` |

Следствие: `0`, `false`, `null`, `[]`, typed array, object могут быть легальными значениями в своем API-контексте. Return-contract берется из WebGL spec, не из `Core` и не из имени hook.

## 2. Ownership

[webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js):

- producer hook-функций;
- owner WebGL domain policy;
- applies WebGL dictionary/storage into `C.state.__WEBGL_STATE__`;
- экспортирует `window.webglHooks`;
- module/domain/preflight diag пишет через `__webglDiag(...)`.

[WEBGL_DICKts.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/WEBGL_DICKts.js):

- producer словаря WebGL whitelist/capability-storage;
- не является самостоятельным policy-owner;
- не имеет отдельного module identity: `diagTag: "webglstorage"` допустим только как subtag producer-storage шага;
- словарь применяет `WebglPatchModule`, а не сам dictionary file.

[context.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/core/context.js):

- owner hook-layer execution;
- регистрирует hook-list'ы в `FernwehContext`;
- ставит issued own wrappers на WebGL instance;
- execution/access diag пишет через `emitContextDiag(...)` / `emitWebGLAccess(...)`;
- auxiliary outward monitor path `emitWebGLMonitor(...)` обязан синхронизироваться с `.diag` как событие `context:webgl:monitor`.

`FernwehContext`:

- hidden bootstrap container;
- не public API;
- `C.state.__WEBGL_STATE__` является canonical WebGL module-state owner-route;
- `window.webglHooks` является export-surface функций, не owner-state.

## 3. Текущий WebGL runtime path

Вход:

`canvas.getContext("webgl"|"experimental-webgl"|"webgl2")`

Дальше:

`ctx -> installIssuedWebGLMethods(ctx) -> methodPlan -> defineIssuedMethod(ctx, proto, method, wrapped)`

Итог:

- patch ставится как own method на конкретный WebGL instance `ctx`;
- native refs берутся из `resolveKeptNative(proto, method) || proto[method]`;
- старый prototype `patchMethod(...)` не является основной точкой issued WebGL runtime.

Основная точка WebGL runtime/logging: `installIssuedWebGLMethods(ctx)`.

## 4. Method plan

| Method | Hook-list |
|---|---|
| `getParameter` | `C.webglGetParameterHooks` |
| `getSupportedExtensions` | `C.webglGetSupportedExtensionsHooks` |
| `getExtension` | `C.webglGetExtensionHooks` |
| `readPixels` | `C.webglReadPixelsHooks` |
| `getShaderPrecisionFormat` | `C.webglGetShaderPrecisionFormatHooks` |
| `shaderSource` | `C.webglShaderSourceHooks` |
| `getUniform` | `C.webglGetUniformHooks` |

Контроль соответствия:

1. method есть в registrar;
2. method есть в `methodPlan`;
3. hook-list не пустой;
4. native `orig` найден;
5. wrapper поставлен через `defineIssuedMethod(...)`.

## 5. Обычный executor contract

Ветка для всех WebGL methods, кроме `post_orig_once`:

`hook.apply(self, [orig, ...patched])`

Executor трактует return hook строго так:

| Hook return | Executor action | Native после hook | Consumer output | Access log source |
|---|---|---|---|---|
| `undefined` | pass-through | да, `orig.apply(self, patched)` | native result | `issued_native` |
| `Array` | args substitution: `patched = res` | да, с новыми args | native result | `issued_native` |
| любое другое значение | final override: `return res` | нет | ровно `res` | `issued_override` |

Критично:

- `0` = final override;
- `null` = final override;
- `false` = final override;
- `''` = final override;
- object / typed array = final override;
- только `undefined` означает "пусть executor вызовет native";
- `Array` никогда не является result override в текущем executor contract.

## 6. `readPixels` special mode

[webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js) задает:

`C.webglReadPixelsHooks.mode = C.__hookModeStore.post_orig_once`

Свойство ставится через `Object.defineProperty(..., enumerable:false)`.

Executor path:

1. `out = orig.apply(self, args)`.
2. Native `readPixels` вызывается первым и ровно один раз.
3. Hook получает `hook.apply(self, [forbidOrigCall, ...args, out])`.
4. Hook return игнорируется.
5. Наружу возвращается `out`.

Нормативно `readPixels` возвращает `undefined`; смысл операции в side-effect: заполнить `pixels`. Поэтому hook должен менять buffer после native readback.

`readPixels` должен входить в `shouldLogWebGLAccess()`, потому что runtime-событие всё равно создаётся в post-orig path и должно быть наблюдаемо как `source: issued_native_post_orig_once`.

## 7. Hook return map

| Method | Hook | Hook return | Executor result | Consumer output |
|---|---|---|---|---|
| `getParameter` | `webglGetParameterMask` | profile vendor/renderer string | final override | profile string |
| `getParameter` | `webglGetParameterMask` | `undefined` | pass-through | native `getParameter` |
| `getParameter` | `webglWhitelistParameterHook` | всегда `undefined` сейчас | pass-through | native `getParameter` |
| `getSupportedExtensions` | `webglGetSupportedExtensionsPatch` | `undefined` при empty whitelist | pass-through | native extensions/null |
| `getSupportedExtensions` | `webglGetSupportedExtensionsPatch` | non-array native `res` | final override | `res`, например `null` |
| `getSupportedExtensions` | `webglGetSupportedExtensionsPatch` | filtered `Array` | final override | filtered extension list |
| `getExtension` | `webglGetExtensionPatch` | `undefined` при empty whitelist | pass-through | native object/null |
| `getExtension` | `webglGetExtensionPatch` | `null` если name blocked | final override | `null` |
| `getExtension` | `webglGetExtensionPatch` | `res` после internal `Reflect.apply(orig, ...)` | final override | native/patched extension object/null |
| `readPixels` | `webglReadPixelsHook` | ignored | post native buffer mutation | native `undefined`, mutated buffer |
| `getShaderPrecisionFormat` | `webglGetShaderPrecisionFormatHook` | `null` / falsy native `res` | final override | `null` / native falsy |
| `getShaderPrecisionFormat` | `webglGetShaderPrecisionFormatHook` | descriptor-preserved object | final override | patched precision object |
| `getShaderPrecisionFormat` | `webglGetShaderPrecisionFormatHook` | native object fallback | final override | native object |
| `shaderSource` | `webglShaderSourceHook` | `Array` | args substitution | native `undefined` after changed source |
| `shaderSource` | `webglShaderSourceHook` | `undefined` | pass-through | native `undefined` |
| `getUniform` | `webglGetUniformHook` | `null` / `undefined` | final override if returned | same value |
| `getUniform` | `webglGetUniformHook` | `0`, non-finite number | final override | same number |
| `getUniform` | `webglGetUniformHook` | finite non-zero number + noise | final override | adjusted number |
| `getUniform` | `webglGetUniformHook` | typed array / boolean / other native `res` | final override | same object/value |

Executor exception:

`Array` remains args substitution for methods such as `shaderSource`, but `getSupportedExtensions` returns `sequence<DOMString>?`; therefore a filtered `Array` from `webglGetSupportedExtensionsPatch` is a final result override, not substituted args.

## 8. Logging map

`context:webgl:access`

- emitted by `emitWebGLAccess(...)`;
- not debug-gated;
- filtered by `shouldLogWebGLAccess(method)`;
- current allow-list: `getParameter`, `getSupportedExtensions`, `getExtension`, `readPixels`, `getShaderPrecisionFormat`, `shaderSource`, `getUniform`;
- logs `data.extra.method`, `source`, `hook`, `request`, `args`, `result`, `resultMeta`.

`source: issued_native`

- hook returned `undefined`, or hook returned `Array` and native was called with substituted args;
- logged `result` is native output after final `orig.apply(...)`.

`source: issued_override`

- hook returned non-`undefined` and non-`Array`;
- logged `result` is exactly the value returned to consumer.

`source: issued_native_post_orig_once`

- used by `readPixels` path;
- logged through `context:webgl:access` because `readPixels` is included in `shouldLogWebGLAccess()`.

`context:issued_webgl:*`

- executor health / controlled exits;
- preflight: `ctx_missing`, `proto_rejected`, `hooks_missing`, `proto_missing`;
- apply: `already_patched`;
- hook error: `failed`, `post_failed`;
- override event: `context:issued_webgl:hook:override`.

Override event caveat:

- `WEBGL_OVERRIDE_DIAG_LOG` is `true`;
- but event is still gated by `__loggerRoot.__DEBUG__` and `WEBGLlogger !== false`;
- so override access is logged in `context:webgl:access`, but debug override event may be absent in normal mode.

`emitWebGLMonitor(...)`

- auxiliary outward monitor path only;
- used in override branch only when `WEBGL_OVERRIDE_LOG === true`;
- current default: `false`;
- not a replacement for `__DEGRADE__.diag`;
- before pushing to `__pushWebGLMonitor__`, it emits paired `.diag` event `context:webgl:monitor` with `module: "webgl"`, `surface: "webgl"`;
- absence of `__pushWebGLMonitor__` must not split the logging model: the mandatory WebGL-domain event is still `.diag`.

[webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js) `__webglDiag(...)`

- producer/module diagnostics;
- used for guard/preflight/storage/export/domain failures;
- uses `diagTag: "webglstorage"` only for dictionary/storage apply events under `module: "webgl"`, `surface: "webgl"`;
- do not migrate to [context.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/core/context.js) if the event is born in [webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js).

## 9. Control checklist

Для проверки WebGL behavior/logging:

1. Method присутствует в `methodPlan`.
2. Hook-list registrar указывает на тот же list.
3. Hook return в [webgl.js](https://github.com/zugdurchfahrt/seed-noise-consistency/blob/borderline/assets/scripts/window/patches/graphics/webgl.js) классифицирован как `undefined`, `Array`, или final value.
4. Executor path определяет, вызывается ли native после hook.
5. Consumer output соответствует WebGL spec return.
6. Method присутствует или отсутствует в `shouldLogWebGLAccess()` осознанно; `readPixels` должен присутствовать.
7. Для `readPixels` контролируется buffer side-effect, а не return value.
8. Для `getSupportedExtensions` returned `Array` является output override, потому что WebGL API возвращает `sequence<DOMString>?`.

## 10. WebGL falsy rule

Do not write:

`if (!res) fallback`

Use only API-specific checks:

- `undefined` means pass-through only in hook contract;
- `null` can be normative output for nullable WebGL APIs;
- `0` can be normative output for numeric WebGL APIs;
- `false` can be normative output for boolean WebGL APIs;
- `[]` can be normative output for sequence APIs;
- typed arrays are normative outputs for several WebGL queries.

If value is valid by WebGL spec, do not convert it into fallback just because it is falsy.

## 11. Known swallow points

These are static observations, not requested fixes:

- `emitWebGLMonitor(...)` has safe-noop `catch (_) {}`.
- `emitWebGLAccess(...)` has safe-noop `catch (_) {}`.
- `emitContextDiag(...)` has safe-noop on logger emission failure.

This matches the logger-adapter safe-noop idea, but it means absence of a log is not proof that the WebGL event did not happen.
