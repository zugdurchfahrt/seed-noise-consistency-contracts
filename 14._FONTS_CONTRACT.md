# Fonts Compound Contract

## 1. Назначение

Шрифтовой compound отвечает за детерминированную подготовку, транспорт, регистрацию и использование managed web-fonts внутри window runtime. Он не является серверным HTML-механизмом и не должен создавать публичные служебные API. Все внутренние данные живут в hidden state `FernwehContext`.


Файл описывает фактическую схему завимисмостей, подтвержденную текущими модулями:

- [font_module.js](/c:/55555/switch/Evensteam/sunami/assets/scripts/window/patches/media/font_module.js)
- [rand_met.py](/c:/55555/switch/Evensteam/sunami/tools/generators/rand_met.py)
- [canvas.js](/c:/55555/switch/Evensteam/sunami/assets/scripts/window/patches/graphics/canvas.js)
- [context.js](/c:/55555/switch/Evensteam/sunami/assets/scripts/window/core/context.js)
- [bootstrap_hide.js](/c:/55555/switch/Evensteam/sunami/assets/scripts/window/core/bootstrap_hide.js)




Нормативные внешние API-ориентиры:

- CSS Font Loading API
- `FontFace`
- `FontFaceSet`
- `CanvasRenderingContext2D.measureText`
- Web IDL / ECMAScript descriptor, receiver and native abuse/error paths










Главная задача compound:

1. Сгенерировать профильный набор шрифтов из локального пула.
2. Перенести runtime-конфиг в hidden state.
3. Загрузить managed `FontFace` через нативный browser path.
4. Синхронизировать готовность шрифтов с canvas/text metrics consumer.
5. Сохранить нативные descriptor/receiver/error-path инварианты public APIs.

## 2. Canonical Ownership

Единственный canonical owner шрифтовой ветки:

```js
FernwehContext.state.__FONTS__
```

Схема slot:

```js
C.state.__FONTS__ = {
  __STATE__: {
    ready: false,
    error: null,
    awaitReady: null,
    awaitReadyStatus: null,
    awaitReadyResolve: null,
    awaitReadyReject: null,
    familySnapshot: {
      allowedFamilies: null,
      runtimeFamilies: new Set(),
      platformDom: null,
      versionToken: null
    }
  },
  __CONFIG__: {
    configs: []
  }
}
```

Правила ownership:

- `bootstrap_hide.js` создает `C.state`, `C.state.__FONTS__`, `__STATE__`, `__CONFIG__`.
- `font_patch.generated.js` заполняет только `C.state.__FONTS__.__CONFIG__.configs`.
- `font_module.js` валидирует существование slot, читает config и наполняет runtime state.
- `canvas.js` является consumer only и не создает fonts state/config.
- `context.js` не является owner шрифтов; он является carrier/gateway для canvas hooks и default ctx2d font state.

Запрещенные/устаревшие canonical paths:

- `C.state.__FONTS_STATE__`
- `C.state.__FONTS_CONFIG__`
- любые downstream-created aliases для fonts state/config

## 3. Bootstrap Layer

`bootstrap_hide.js` обязан создать fonts root до загрузки generated patch и runtime module.

Bootstrap создает пустой config:

```js
C.state.__FONTS__.__CONFIG__.configs = []
```

Bootstrap создает state с начальными значениями:

- `ready = false`
- `error = null`
- `awaitReady = null`
- `awaitReadyStatus = null`
- `awaitReadyResolve = null`
- `awaitReadyReject = null`
- `familySnapshot.allowedFamilies = null`
- `familySnapshot.runtimeFamilies = new Set()`
- `familySnapshot.platformDom = null`
- `familySnapshot.versionToken = null`

Если эти слоты отсутствуют, это pipeline missing data, а не штатный runtime-вариант.

## 4. Generator Layer

Источник генерации: `sunami/tools/generators/rand_met.py`.

Выходы генератора:

- `sunami/assets/Manifest/fonts-manifest.json`
- `sunami/assets/JS_fonts_patch/font_patch.generated.js`

Входной пул:

- новые `.woff2` берутся из `assets/fonts_raw`;
- платформенный каталог: `assets/generated_fonts/Win32` или `assets/generated_fonts/MacIntel`;
- индекс: `fonts_index.json`;
- side-cache data URL: `cache_data/<md5>.b64`.

Платформа нормализуется только в:

- `Win32`
- `MacIntel`

Любая другая платформа вызывает `ValueError`.

Seed / derivative rules:

- `_module_derivative()` обязателен и fail-fast при отсутствии `RAND_MET_DERIVATIVE`;
- локальный RNG строится через `_derive_local_rng(...)`;
- генерация не должна зависеть от неинициализированного global random state;
- `_META_RNG` обязателен для metadata generation.

Количество:

- `FONTS_MIN_N`, default `56`;
- `FONTS_MAX_N`, default `58`;
- итоговый `N` выбирается детерминированно из platform seed parts;
- если построено меньше `N`, генератор бросает `RuntimeError`.

Фильтры и проверки:

- payload должен быть валидным `wOF2`;
- `md5` обязателен;
- duplicate `md5` пропускается;
- icon/font packs и emoji/color edge cases фильтруются до попадания в runtime config;
- `max_family_repeats = 5`;
- `cssLoadQuery` строится только из `cssFamily`, `style`, `weight`.

Текущее поведение, не являющееся доказательством уникальности:

- duplicate `uniq_triple = (resolved_family, full_name, postscript)` сейчас только логируется как keep и не прерывает добавление;
- duplicate `cssLoadQuery` сейчас только логируется как keep и не прерывает добавление.

Это не должно документироваться как строгая гарантия уникальности.

## 5. Generated Transport

`font_patch.template.j2` рендерит generated patch, который:

1. Находит `globalThis.FernwehContext`.
2. Требует `C.state`.
3. Требует `C.state.__FONTS__`.
4. Требует `C.state.__FONTS__.__CONFIG__`.
5. Присваивает `slot.configs = <configs_json>`.

Generated patch не создает fonts root и не создает `__CONFIG__`. Если slot отсутствует, он бросает ошибку.

Runtime config entry в `font_patch.generated.js` содержит:

- `name`
- `family`
- `cssFamily`
- `cssLoadQuery`
- `full_name`
- `postscript_name`
- `url`
- `platform_id`
- `platform_dom`
- `weight`
- `style`

`url` существует только в runtime JS config и содержит:

```txt
data:font/woff2;base64,...
```

`fonts-manifest.json` является metadata/manifest artifact и не является полным runtime transport. В текущем состоянии manifest payload не несет `url`; data URL переносится в `font_patch.generated.js`.

## 6. Runtime Config Semantics

`font_module.js` читает:

```js
C.state.__FONTS__.__CONFIG__.configs
```

Платформенная фильтрация:

```js
cfg.platform_dom === C.state.__ENV_PROFILE__.__PLATFORM__.domPlatform
```

Если хотя бы одна запись имеет `platform_dom`, используется platform-scoped subset. Если platform field отсутствует у всех записей, используется весь массив.

Runtime family:

```js
fam = cfg.cssFamily || cfg.family
```

`cssFamily` является preferred runtime CSS family. `_derive_css_family()` не синтезирует fallback из filename: если `family` отсутствует, `cssFamily` остается пустым, а `_derive_css_load_query()` должен fail-fast на missing family.

`cssLoadQuery` является сгенерированной CSS font shorthand строкой для диагностики/transport signature, но текущий public `FontFaceSet.check/load` не использует ее как активный gate.

## 7. FontFace Constructor Policy

`font_module.js` патчит `FontFace` как data target через общий `Core.applyTargets` path и `__wrapNativeCtor`.

Требования:

- wrapper обязан сохранять native constructor/prototype/class-extension инварианты;
- source sanitization не должна ломать native receiver/error path;
- не допускается public leakage служебных данных;
- unexpected source type диагностируется, но не должен превращаться в невалидный public API shape.

`sanitizeFontFaceSource(source, family, descriptors)` работает только с `source`:

1. Разбирает top-level comma-separated `src`.
2. Выделяет `local(...)`.
3. Сохраняет non-local entries.
4. Пытается найти managed config через `matchRuntimeFontConfig(family, descriptors)`.

`matchRuntimeFontConfig` сравнивает:

- normalized requested family;
- `cfg.cssFamily || cfg.family`;
- fallback match по `cfg.full_name` и `cfg.postscript_name`;
- `style`, default `normal`;
- `weight`, default `normal`.

Ветки:

- local-only и matched managed config с `data:font/woff2;base64,...` -> заменить source на `url("<data>") format("woff2")`;
- local-only без доказанного managed match -> оставить native local source и записать `fonts:fontface:local_only_passthrough_not_proven`;
- mixed `local(...) + url(...)` -> убрать local entries и оставить non-local entries;
- non-local only -> оставить source без подмены.

Диагностические события:

- `fonts:fontface:local_only_replaced_with_managed_src`
- `fonts:fontface:local_only_passthrough_not_proven`
- `fonts:fontface:source_unexpected_type`

## 8. FontFaceSet Policy

Текущий public carrier status:

- `FontFaceSet.ready` патчится как accessor wrapper и проксирует native getter через `Reflect.apply`.
- `FontFaceSet.check` оставлен native.
- `FontFaceSet.forEach` оставлен native.
- `FontFaceSet.load` оставлен native.

Причина native passthrough:

- сохранить native abuse/error path;
- не ломать descriptor/receiver invariants;
- не вводить неадмиссимый public method carrier.

Коды диагностики:

- `fonts:method:check_native_passthrough`
- `fonts:method:forEach_native_passthrough`
- `fonts:promise:load_native_passthrough`

Старое утверждение, что compound активно фильтрует `FontFaceSet.check(query)` и `FontFaceSet.load(query, text)`, больше не является контрактом текущей реализации.

## 9. Load And Settle Lifecycle

Window branch активен только если есть:

- `document`;
- `document.fonts`;
- `document.fonts.add`.

Для каждой platform-scoped config entry:

```js
const fam = f.cssFamily || f.family;
const src = `url(${JSON.stringify(f.url)}) format("woff2")`;
const ff = new FontFace(fam, src, {
  weight: f.weight || 'normal',
  style: f.style || 'normal',
  display: 'swap'
});
await ff.load();
document.fonts.add(loaded);
```

Перед загрузкой runtime state переходит в loading/pending состояние. После успешной загрузки всех entries runtime дожидается:

1. native `document.fonts.ready`;
2. double `requestAnimationFrame` barrier.

Только после этого:

- `__STATE__.ready = true`;
- `__STATE__.error = null`;
- `awaitReady` settled/resolved;
- dispatch `fontsready`;
- обновляется `familySnapshot.versionToken`.

Если есть failures:

- `ready = false`;
- `error` получает строковое описание первой ошибки;
- `awaitReady` rejected;
- пишется `fonts:load_settled_with_failures`.

Ключевые runtime diagnostics:

- `fonts:filtered_empty`
- `fonts:filtered_count`
- `fonts:load_item_failed`
- `fonts:document_fonts_add_failed`
- `fonts:load_settled`
- `fonts:load_settled_with_failures`
- `fonts:load_unexpected_rejection`

## 10. Family Snapshot

`familySnapshot` является shared epoch state для fonts consumers.

Состав:

- `allowedFamilies`: Set из platform-scoped configs, по `cfg.cssFamily` и `cfg.family`;
- `runtimeFamilies`: Set из live `FontFaceSet`, включая families, добавленные через runtime `FontFace`;
- `platformDom`: текущий `domPlatform`;
- `versionToken`: строковый epoch token.

`versionToken` должен меняться при изменении:

- platform;
- состава platform-scoped configs;
- live runtime families;
- `ready`;
- `awaitReadyStatus`;
- `error`.

`getSharedFamilyDictionary()` строит union:

```js
allowedFamilies ∪ runtimeFamilies
```

Этот словарь является внутренним состоянием compound. Он не является публичным API и не должен подменять native `FontFaceSet.check/load`.

## 11. Canvas Consumer

`canvas.js` читает только canonical path:

```js
C.state.__FONTS__.__STATE__
```

`applyMeasureTextHook(nativeMetrics, text, font)`:

- получает `fontStr`;
- читает `fontsState.ready`;
- если `ready !== true`, возвращает native `TextMetrics` без post-processing;
- читает `familySnapshot.versionToken`;
- включает `versionToken` в cache key;
- возвращает Proxy над native `TextMetrics`, exposing only native-present metric fields.

Canvas не создает `__FONTS__`, `__STATE__`, `__CONFIG__` и не должен заполнять `configs`.

`measureTextNoiseHook` не меняет width сам по себе; post-processing выполняется только в `applyMeasureTextHook`.

## 12. Context Carrier

`context.js`:

- хранит shared default 2D context font в canvas state;
- читает `ctx.font` через guarded path;
- патчит `CanvasRenderingContext2D.prototype.measureText` через shared patch mechanism;
- вызывает `FernwehHooks.applyMeasureTextHook(m, txt, fontStr)`;
- при hook failure пишет `context:ctx2d:hook:measureText_failed` и возвращает native `TextMetrics`.

`context.js` не читает `C.state.__FONTS__.__CONFIG__` и не является producer шрифтового config.

Связь `context.js -> canvas.js -> fonts state`:

```txt
measureText native result
  -> context.js carrier
  -> canvas.js applyMeasureTextHook
  -> C.state.__FONTS__.__STATE__.ready/versionToken
```

## 13. DOM Override

Текущий `font_module.js` содержит macOS-only DOM override branch:

- активен только при `domPlatform === 'MacIntel'`;
- берет первый filtered font family;
- добавляет/обновляет `<style id="force-font-override">`;
- выставляет `font-family: <managed family>, Helvetica, Arial, sans-serif !important`.

Это отдельная runtime ветка, а не canonical source of truth. Canonical source остается `C.state.__FONTS__.__CONFIG__.configs` и `C.state.__FONTS__.__STATE__`.

## 14. Diagnostics And Rollback

Ошибки compound должны идти через `__DEGRADE__.diag`/module logger path, а не через silent swallow.

Типы:

- pipeline missing data: отсутствует `FernwehContext`, `state`, `__FONTS__`, `__STATE__`, `__CONFIG__`, required config fields;
- browser structure missing data: отсутствует `document.fonts`, native constructor/accessor, browser API shape;
- runtime failure: load/add/settle/event/DOM operation failure.

`font_module.js` сохраняет prior runtime state и при fatal path пытается rollback к clone state. Rollback failure должен диагностироваться.

Коды rollback/fatal:

- `fonts:rollback_failed`
- `fonts:fatal`

## 15. Current Contract Gaps

Ниже текущие места, где поведение не является строгим fail-fast, хотя диагностируется:

- Missing `domPlatform` приводит к `fonts:nav_platform_missing`, попытке восстановить `awaitReady` из native `document.fonts.ready` и return. Это текущий compatibility skip, не доказанный strict fail-fast.
- Missing/empty filtered configs приводит к диагностике `fonts:filtered_empty`, но сама ветка продолжает работать до последующих условий. Это не должно трактоваться как успешное наличие fonts payload.
- Duplicate `uniq_triple` и duplicate `cssLoadQuery` в `rand_met.py` сейчас логируются как keep и не являются hard rejection.
- `context.js` при failure `applyMeasureTextHook` возвращает native metrics после диагностики. Это current native-preserving fallback, но не является подтверждением успешного fonts consumer path.

Эти пункты фиксируют фактическое состояние repo. Если требуется strict fail-fast по всем пунктам, это отдельная правка реализации, а не документа.

## 16. Deprecated Statements

В контракте больше нельзя утверждать:

- что canonical owner находится в top-level `C.state.__FONTS_STATE__` или `C.state.__FONTS_CONFIG__`;
- что `fontFamily` является runtime ключом;
- что `FontFaceSet.check` и `FontFaceSet.load` actively patched/gated текущим runtime;
- что `fonts-manifest.json` является полным transport с `data:font/woff2;base64,...`;
- что фиксированные исторические числа вроде `37`, `30`, `4`, `51` являются contract values;
- что canvas может создавать или чинить fonts config/state.
